# Lu-Core

Lu core: a local AI desktop that looks like Jan or LM Studio from the outside and carries a durable memory (ANSF), a small set of built-in tools, and checks that make a model's work trustworthy.

Status: designed. No code yet. Start with `docs/design/BRIEF_FOR_OPUS.md`.

- `docs/design/BRIEF_FOR_OPUS.md`: handoff brief, build order, rules, reporting format
- `docs/design/ANSF_MEMORY_SPEC.md`: memory design
- `docs/design/EXECUTION_LAYER_SPEC.md`: tools, authority, verification and recovery
- `docs/design/CORE_COVERAGE_AND_PLATFORM_SPEC.md`: coverage map, resources, model search, backends

All work goes to `main`. No branches, no pull requests. CI is for verification only.
